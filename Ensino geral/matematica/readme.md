# Matemática

## Observação sobre os estudos

O conteúdo registrado nesta pasta representa o que já foi estudado nos cursos de Matemática. Todo curso em andamento pode ainda conter estudos faltantes ou lacunas em determinados assuntos, mesmo quando algumas unidades aparecem como concluídas.

Por isso, cada curso deve ser analisado individualmente para identificar o que ainda falta estudar, revisar ou aprofundar. As lacunas encontradas devem ser registradas neste material para orientar os próximos estudos.
