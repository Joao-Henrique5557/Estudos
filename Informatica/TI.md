# Ramos da Área de Tecnologia da Informação (TI)

A área de **Tecnologia da Informação (TI)** é composta por diversos ramos especializados, que abrangem desde o desenvolvimento de sistemas até infraestrutura, dados, segurança, inteligência artificial e gestão.

---

## 1. Desenvolvimento de Software

Área responsável pela criação, manutenção e evolução de aplicações e sistemas.

- **Front-end**
  - HTML, CSS, JavaScript
  - React, Vue, Angular
  - Interfaces e aplicações web

- **Back-end**
  - APIs
  - Servidores
  - Regras de negócio
  - Node.js, Java, Python, C#, Go etc.

- **Full Stack**
  - Front-end + Back-end
  - Integração com APIs
  - Bancos de dados
  - Deploy

- **Desenvolvimento Mobile**
  - Android
  - iOS
  - React Native
  - Flutter
  - Kotlin
  - Swift

- **Desenvolvimento Desktop**
  - Windows
  - Linux
  - macOS
  - Electron
  - .NET
  - Java

- **Desenvolvimento de Jogos**
  - Unity
  - Unreal Engine
  - Godot
  - Game Design
  - Programação de jogos
  - Computação gráfica

- **Desenvolvimento de Sistemas Embarcados**
  - Microcontroladores
  - Firmware
  - RTOS
  - C/C++
  - Arduino
  - ESP32
